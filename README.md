# 🏋️ GYM FIT | Elite Performance Tracking

A premium, technically elite fitness tracking web application built with **React**, **Vite**, and **Firebase**. Designed for professional athletes who demand data-driven insights with a minimalist, high-performance aesthetic.

![Landing Preview](https://lh3.googleusercontent.com/aida-public/AB6AXuCHX1hXz0_F29fG98F8z_f36g2Wp_F6m2T5x8n4v9L3y7w8)

## ✨ Key Features
- **Dynamic Bento Dashboard**: A highly polished, data-rich overview of your vitals and training progress.
- **Firebase Authentication**: Secure Sign-in and Registration flow with real-time state management.
- **Glassmorphism UI**: A modern "technical minimalism" design system featuring blurred panels and premium gradients.
- **Fluid Animations**: Smooth page transitions and micro-interactions powered by **Framer Motion**.
- **Responsive Design**: Fully optimized for elite performance on mobile, tablet, and desktop devices.

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS (PostCSS)
- **Animations**: Framer Motion
- **Backend/Auth**: Firebase (Auth)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/LIMRUIXUAN/ai_cook_workshop.git
   cd ai_cook_workshop
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Firebase**:
   - Create a project in the [Firebase Console](https://console.firebase.google.com/).
   - Enable **Email/Password** authentication in the Auth tab.
   - Replace the config in `src/firebase.js` with your project's credentials.

4. **Run the development server**:
   ```bash
   npm run dev
   ```
